# stevesparks.dev feedback

Corrections and suggestions for [stevesparks.dev](https://stevesparks.dev), including the book *AI, from the Parts Up*.

Found an error? [Open a correction](../../issues/new?template=correction.yml). Please name the page, quote the claim, and link a source if you have one. Accepted corrections are listed on the page they change.

This repository holds issues only; the site's code is private.
